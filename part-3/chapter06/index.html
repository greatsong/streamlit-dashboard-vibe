📚 핵심 개념

섹션 제목: “📚 핵심 개념”

개념: 프로젝트 기반 학습

섹션 제목: “개념: 프로젝트 기반 학습”

프로젝트 기반 학습은 마치 요리 대회와 같아요. 지금까지 배운 재료 손질법, 조리법을 활용해 완성된 요리를 만드는 거죠. 단순히 기술을 따라하는 것이 아니라, 목표를 정하고 AI와 협업하며 실제 결과물을 완성하는 과정입니다.

정확히 말하면, 앞서 배운 모든 기술(프롬프트 엔지니어링, 바이브코딩, 데이터 시각화)을 종합하여 실무에 적용 가능한 프로젝트를 완성하는 학습 방법입니다.

예시: 우리 학교 급식 만족도 대시보드, 개인 운동 기록 분석 도구, 지역 날씨 트렌드 시각화 등

💡 왜 이걸 배우나요?

섹션 제목: “💡 왜 이걸 배우나요?”

프로젝트 기반 학습은 실제 데이터 분석가, 개발자들이 업무에서 사용하는 방식입니다. Netflix의 콘텐츠 추천 시스템, 카카오의 실시간 교통 정보, 배달의민족의 주문 분석 대시보드 모두 이런 방식으로 만들어집니다.

실제 활용 분야:

  • 🏢 회사 매출 분석 대시보드
  • 🎮 게임 유저 행동 분석
  • 📱 앱 사용 통계 모니터링

🚀 더 해보기

섹션 제목: “🚀 더 해보기”

⭐ 기본: 차트 색상이나 제목을 변경해보세요

힌트 plotly의 color 매개변수를 사용해보세요: `color='대륙'`

⭐⭐ 응용: 새로운 데이터 컬럼(GDP, 면적 등)을 추가하고 차트를 만들어보세요

힌트 산점도(scatter)로 인구 vs GDP 관계를 시각화해보세요

⭐⭐⭐ 도전: 실시간 데이터(날씨 API, 주식 API 등)를 연결해보세요

힌트 requests 라이브러리로 무료 API를 호출하고 st.rerun()으로 자동 새로고침

⚠️ 주의할 점

섹션 제목: “⚠️ 주의할 점”
  • AI가 제공한 코드를 맹신하지 마세요 - 항상 실행해보고 이해하려 노력하세요
  • 처음부터 완벽한 프로젝트를 만들려 하지 마세요 - 작은 것부터 시작해서 점차 개선하세요

✅ 스스로 점검하기

섹션 제목: “✅ 스스로 점검하기”
  1. 나만의 프로젝트 주제를 하나 정하고 AI에게 도움을 요청할 수 있나요?
정답 확인 구체적인 조건(시간, 기술 수준, 관심사)을 포함한 프롬프트를 작성하면 됩니다.
  1. 완성된 프로젝트를 어떻게 다른 사람들과 공유할 수 있을까요?
정답 확인 Streamlit Cloud에 배포하거나 GitHub에 코드를 올려 공유할 수 있습니다.
  1. 이 프로젝트를 통해 어떤 새로운 인사이트를 발견했나요?
정답 확인 개인마다 다르겠지만, 데이터를 직접 다루며 패턴이나 트렌드를 발견했다면 성공입니다!
